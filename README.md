# Employee Management System - Frontend

This is the **frontend** of the Employee Management System, built using **React, React Router, Material UI, Axios, and Tailwind CSS**.

## 🛠 Tech Stack

- **React** - For building UI components.
- **React Router** - For client-side routing.
- **Material UI (MUI)** - For UI components and styling.
- **Tailwind CSS** - For additional styling.
- **Axios** - For API calls.

## 🚀 Getting Started

### 1️⃣ Prerequisites

Make sure you have the following installed:

- Node.js (v18)
- npm

### 2️⃣ Clone the Repository

```sh
git clone https://github.com/shaikkarimulla4741/cloud-ems-frontend.git
cd cloud-ems-frontend
```

### 3️⃣ Install Dependencies

```sh
npm install  
```

### 4️⃣ Start the Development Server

```sh
npm run dev
```

This will start the frontend at `http://localhost:5173/`.


## 🔌 API Integration

The frontend communicates with a **Spring Boot backend** using Axios.


## 🖌 UI Styling

We use:

- **Material UI (MUI)** for buttons, cards, modals, etc.
- **Tailwind CSS** for utility-based styling.


## 🔐 Authentication & Authorization

- JWT-based authentication.
- Role-based access (HR can manage employees, Employees can view their profiles).
